# Before uploading (two items live only on your machine)
1. Copy your local probe/corpus/ (all ten .txt and .pdf files) into corpus/ here;
   this bundle ships with darkside and protodune only.
2. Copy your local probe/prompts/ (40 files) into prompts/, replacing PLACEHOLDER.
3. Verify: python analysis/analyze.py runs clean end to end.
4. GitHub: create the repository, push this folder, tag a release v1.0.
5. Zenodo: link the GitHub repository (or upload the zip), publish, copy the DOI.
6. Put the DOI into the manuscript bibitem "atlasdata" and into CITATION.cff.
